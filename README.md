# RotaEşit kampüs verisi

KSÜ Avşar Kampüsü erişilebilir yol tarifi uygulaması (RotaEşit) için kampüs verisi.

Kaynaklar: OpenStreetMap katkıda bulunanlar (ODbL 1.0, https://www.openstreetmap.org/copyright), harita.ksu.edu.tr ve RotaEşit ekibinin saha ölçümleri.
Bu veri seti ODbL 1.0 lisansıyla paylaşılır.
